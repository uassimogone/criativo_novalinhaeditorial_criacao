# criativo_novalinhaeditorial_criacao

Gerador automático de criativos da nova linha editorial.

Fluxo inicial:
1. pautas aprovadas pelo usuário no ChatGPT;
2. registro em data/pautas_aprovadas.json;
3. geração de carrosséis, estáticos e roteiros;
4. exportação de pacote READY_TO_PUBLISH;
5. publicação futura por repositório separado.
