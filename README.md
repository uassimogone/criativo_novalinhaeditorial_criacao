# criativo_novalinhaeditorial_criacao

Gerador automático de criativos da nova linha editorial.

Fluxo inicial:
1. pautas aprovadas pelo usuário no ChatGPT;
2. registro em data/pautas_aprovadas.json;
3. geração de carrosséis, estáticos e roteiros;
4. exportação de pacote READY_TO_PUBLISH;
5. publicação futura por repositório separado.


## Direção visual aprovada
O padrão oficial passa a ser editorial premium, com referência de linguagem visual em Forbes e ritmo/tese em Tio Huli, sem reprodução de identidade proprietária.

Princípios:
- 5 slides como padrão;
- capa com imagem real forte e headline curta;
- slide 4 como segundo momento visual;
- menos texto;
- tipografia de alta presença;
- fechamento de tese, não CTA genérico.
